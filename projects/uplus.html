Website Growth & Analytics Project

U+ Community Growth & Program Discovery Optimization

A multi-part website optimization project focused on improving program discovery, CTA clarity, content quality, accessibility, SEO, and future conversion measurement for U+ Community.

React Python SQL Power BI Figma SEO Accessibility QA
View GitHub Repository ↗

Overview

This project reviewed U+ Community's public website and created a structured system for improving how users discover programs and move toward important actions such as registration, volunteering, event RSVPs, job applications, mailing-list signups, and contact.

The work combined website auditing, automation, data modeling, dashboard reporting, UX analysis, frontend prototyping, and measurement planning.

The Problem

Program information was spread across multiple pages, CTA wording was not always consistent, some content required freshness review, and there was no centralized Program Discovery experience.

The project also identified the need for a clearer future tracking system so website engagement and conversion actions could be measured consistently.

What I Built

Website Audit

Reviewed public U+ pages for page structure, CTAs, links, content freshness, SEO, accessibility, and UX issues.

Python Audit Pipeline

Built a Python-based audit workflow that generated structured page, CTA, and link audit data for analysis.

SQL Data Model

Created a SQLite analytical model for pages, CTAs, links, audit results, and future analytics data.

Program Discovery Prototype

Built a responsive React prototype with keyword search, filtering, program cards, featured opportunities, and clear calls-to-action.

Tracking Plan

Defined a future event-tracking structure for program card views, clicks, volunteer applications, registrations, RSVPs, mailing-list actions, contact actions, and donations.

Power BI Dashboard

Developed a three-page management dashboard covering growth overview, program discovery and conversion, and technical and content quality.

Key Findings

  • 10 public pages were reviewed.
  • 53 CTAs were analyzed.
  • 65 links were reviewed.
  • 61 links were working.
  • 3 links were unresolved.
  • 1 incorrect destination was identified.
  • 2 pages had missing or competing CTA issues.
  • 24 improvement recommendations were documented.

Quality & Testing

The prototype was tested across 375px, 768px, 1024px, and 1440px widths, with keyboard navigation, focus states, JavaScript console checks, and Lighthouse testing.

Final Lighthouse production-build scores:

  • Performance: 100
  • Accessibility: 95
  • Best Practices: 100
  • SEO: 100

Technology

React, JavaScript, Python, SQLite, SQL, Power BI, Figma, HTML5, CSS3, GitHub, Chrome DevTools, Lighthouse, SEO, WCAG/AODA review.

Outcome

The final deliverable combined a working Program Discovery prototype with a practical analytics and tracking specification. The project demonstrated how web development, automation, data analysis, UX, and reporting can work together to improve a real organization's digital experience.
