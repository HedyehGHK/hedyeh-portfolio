Overview

This project is a responsive front-end website created for a professional counselling practice. The website presents service information, therapist profile content, contact details, and clear navigation in a simple and approachable layout.

The goal was to create a professional online presence that feels trustworthy, easy to navigate, and accessible across desktop and mobile devices.
