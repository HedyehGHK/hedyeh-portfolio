CaseNote AI

An AI-powered application created to help therapists organize clinical notes, identify behavioural patterns, and generate structured case summaries using Google's Gemini API.

01

Overview

CaseNote AI explores how artificial intelligence can assist mental health professionals with clinical documentation. The application analyzes therapy session notes, identifies behavioural patterns, and generates structured summaries to support counsellors during case review.

The project was designed as an exploration of practical AI applications in healthcare, combining modern web technologies with the Gemini API to simplify documentation while keeping the user experience clean and intuitive.
